# Security policy

Please report vulnerabilities privately through [GitHub Security Advisories](https://github.com/lopesDilceu/ReniceProject/security/advisories/new), not through public issues.

## Known issues in v1

The original version (`v1.0-academic`) was coursework and has known vulnerabilities. They are documented publicly in the [initial audit](docs/audit/initial-audit.md) and tracked under the [`security`](https://github.com/lopesDilceu/ReniceProject/labels/security) label. That version was never deployed publicly and must not be.
