# Architecture Decision Records

An ADR records one significant decision: the context, what was decided, the alternatives considered and the consequences. ADRs are immutable once accepted. A changed decision gets a new ADR that supersedes the old one.

Write one whenever a choice has real alternatives and would be expensive to reverse. Copy [`0000-template.md`](0000-template.md) and use the next number.
